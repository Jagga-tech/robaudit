## Hard questions, short answers

Higher cost estimate reduces revenue because progress = incurred ÷ total; bigger total,
smaller share. Not a mistake: an estimate changed. Not "saved": an accounting adjustment,
cash unchanged. Right because four lines of tested arithmetic against an independent answer
key; the model reads, asks, explains, never posts. Hard 606 cases out of scope by policy.
Learns conventions and precedents, not model weights. Controller "no" → stays unposted with
reason. Evidence after posting → posted entry stays, proposal stale, new adjustment.
